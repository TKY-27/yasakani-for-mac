**Secrets redaction:**
- The manifest can declare `"redact": {"values": [...]}` or `"secrets": {"NAME": "value"}`. The runner builds a set of secret strings (values, and maybe names?). Redact in: command args? If the command contains a secret, replace with `"[REDACTED]"`. Also redact in log lines. Also redact in `data` fields of all emitted events (string values scanned, or `str.replace` per line). Implement `Redactor` class:

```python
class Redactor:
    def __init__(self, secrets: Iterable[str]):
        self._secrets = sorted({s for s in secrets if s}, key=len, reverse=True)
    def redact(self, text: str) -> str:
        for s in self._secrets:
            text = text.replace(s, "[REDACTED]")
        return text
```

Apply to all string leaves in events and to captured output lines.

Simplest robust pattern:

```python
async def wait_with_cancel(proc, cancel_event, grace):
    done, _ = await asyncio.wait([proc.wait(), cancel_event.wait()], return_when=asyncio.FIRST_COMPLETED)
    if cancel_event in done:
        proc.terminate()
        try:
            await asyncio.wait_for(proc.wait(), grace)
        except asyncio.TimeoutError:
            proc.kill()
            await proc.wait()
        return None  # cancelled
    return proc.returncode
```

Note: `cancel_event.wait()` task is pending forever — keep it, or cancel when complete. Cancel the cancel-wait task when process ends to avoid leaks.
