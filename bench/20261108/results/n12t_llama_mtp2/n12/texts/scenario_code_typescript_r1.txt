Engine:

`MetricsEngine`:
```ts
type GroupKey = { runId: string; model: string; fixture: string };
class GroupAgg {
  n = 0; mean = 0; m2 = 0; min = Infinity; max = -Infinity;
  reservoir: number[] = [];
  stored = 0;
  add(value): void {
    // Welford update
    this.n += 1;
    const delta = value - this.mean;
    this.mean += delta / this.n;
    this.m2 += delta * (value - this.mean);
    if (value < this.min) this.min = value;
    if (value > this.max) this.max = value;
    if (this.reservoir.length < RESERVOIR_CAP) { this.reservoir.push(value); }
    else {
      const j = randomInt(0, this.n); // reservoir sampling: keep with prob K/n
      if (j < RESERVOIR_CAP) this.reservoir[j] = value;
    }
  }
}
```
Reservoir sampling: for the (i+1)-th item with reservoir size K, generate j uniform in [0, n). If j < K, replace reservoir[j]. This is standard Algorithm R — yes.

Note: sample stddev uses the Welford m2 computed over all n values: std = sqrt(m2/(n-1)).
