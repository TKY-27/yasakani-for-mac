  MedianMaintainer:
  ```ts
  class StreamingMedian {
    private low = new BinaryHeap<number>((a, b) => b - a); // max-heap: a closer to root if a > b
    private high = new BinaryHeap<number>((a, b) => a - b); // min-heap
    private tracked = 0;
    approximate = false;
    
    add(value: number, cap: number): void {
      if (this.tracked >= cap) {
        // evict from the larger side to preserve balance
        if (this.low.size >= this.high.size) this.low.pop(); else this.high.pop();
        this.tracked -= 1;
        this.approximate = true;
      }
      if (this.low.size > 0 && value <= this.low.peek()) this.low.push(value);
      else this.high.push(value);
      // rebalance: allow low.size - high.size ∈ {0,1}
      if (this.low.size - this.high.size > 1) this.high.push(this.low.pop()!);
      else if (this.high.size - this.low.size > 1) this.low.push(this.high.pop()!);
    }
    
    median(): number | null {
      if (this.low.size === 0) {
        if (this.high.size === 0) return null;
        // high has 1 more? invariants allow high.size - low.size ≤ 1, so high=1, low=0
        return this.high.peek();
      }
      if (this.low.size === this.high.size) {
        return (this.low.peek() + this.high.peek()) / 2;
      }
      return this.low.peek();
    }
  }
  ```
  Check invariants: after add and rebalance, |low| - |high| ≤ 1 and |high| - |low| ≤ 1. Initial state: empty. Add: low empty → high. high size 1, low 0 → rebalance? high-low=1, OK. Add: second value: if ≤ high? no wait, low empty → push to high. high size 2 → rebalance: move high.pop() (min) to low. Now low has the min, high has the max. median = average.

  Edge case: value comparison when low empty but high non-empty — condition `low.size > 0 && value <= low.peek()` is false → high.push. That's fine because invariant ensures low ≥ high when both are non-empty.

- **Welford**:
  ```ts
  class RunningMoments {
    n = 0; mean = 0; m2 = 0;
    add(x: number) {
      this.n += 1;
      const delta = x - this.mean;
      this.mean += delta / this.n;
      const delta2 = x - this.mean;
      this.m2 += delta * delta2;
    }
    get sampleVariance(): number | null { return this.n >= 2 ? this.m2 / (this.n - 1) : null; }
    get sampleStddev(): number | null { const v = this.sampleVariance; return v === null || v < 0 ? null : Math.sqrt(v); }
    get sum(): number { return this.mean * this.n; }
  }
  ```
  Note: m2 can go slightly negative due to floating point; clamp.
