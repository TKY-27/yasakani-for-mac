# 发布流程

发布负责人必须严格保留诸如 `request_id`、`max_context`、`kv_dtype` 和 `mtp_rounds` 等标识符。请将正文翻译为中文，但不要翻译代码、JSON 键、命令行标志、文件名或表格中的值。

| Phase | Required evidence | Failure action |
|---|---|---|
| prepare | fixture hash and prompt-token count | stop before generation |
| warmup | one successful unmeasured request | restart the service |
| measure | five sequential responses | invalidate the complete block |
| publish | summary plus per-request rows | withhold the headline |

```json
{"model":"qwen3.6-35b-a3b","max_completion_tokens":1024,"seed":42,"stream":false}
```

## 备注

操作员需检查前缀复用已禁用、缓存命中计数为零，且没有无关的 GPU 进程处于活动状态。自然停止的响应仍视为有效观测；因客户端断开连接而丢失的响应则不视为有效。报告区分了服务器内部的 TTFT 与网络观测时间，并解释首个生成的 token 被分配给 prefill 阶段。

## 双语术语表

| 英文术语 | 中文术语 | 简要说明 |
|---|---|---|
| Release procedure | 发布流程 | 软件或模型版本发布的标准化步骤 |
| Release owner | 发布负责人 | 负责确保发布过程合规与质量的人员 |
| Identifier | 标识符 | 用于唯一识别对象或参数的符号 |
| Request ID | 请求标识符 | 用于追踪特定 API 请求的唯一 ID |
| Max context | 最大上下文长度 | 模型可处理的最大输入 token 数量 |
| KV dtype | 键值数据类型 | 键值缓存中存储的数据精度类型 |
| MTP rounds | 多 token 预测轮数 | 单次前向传播中预测多个 token 的迭代次数 |
| Phase | 阶段 | 发布流程中的特定步骤 |
| Required evidence | 所需证据 | 验证某阶段成功所需的记录或数据 |
| Failure action | 失败处理措施 | 当阶段验证失败时执行的操作 |
| Prepare | 准备 | 发布前的初始化与配置阶段 |
| Fixture hash | 测试夹具哈希 | 用于验证测试数据完整性的哈希值 |
| Prompt-token count | 提示词 token 计数 | 输入提示词中包含的 token 总数 |
| Stop before generation | 生成前停止 | 在开始生成内容前终止流程 |
| Warmup | 预热 | 使系统达到稳定状态的非测量阶段 |
| Unmeasured request | 未测量请求 | 不计入性能统计的测试请求 |
| Restart the service | 重启服务 | 重新启动后端服务以恢复状态 |
| Measure | 测量 | 收集性能指标的阶段 |
| Sequential responses | 顺序响应 | 按顺序生成的多个响应结果 |
| Invalidate the complete block | 使完整数据块失效 | 丢弃当前批次的所有测量数据 |
| Publish | 发布 | 公开最终报告或结果的阶段 |
| Summary | 摘要 | 整体性能或结果的概括性描述 |
| Per-request rows | 每请求行数据 | 针对每个单独请求的详细数据记录 |
| Withhold the headline | 暂缓发布标题 | 在数据不完整时不发布主要结论 |
| Prefix reuse | 前缀复用 | 重用相同前缀的 KV 缓存以加速推理 |
| Cache-hit count | 缓存命中计数 | 成功从缓存中读取数据的次数 |
| GPU process | GPU 进程 | 占用图形处理器资源的运行程序 |
| Valid observation | 有效观测 | 符合实验规范、可用于分析的数据点 |
| Client disconnected | 客户端断开连接 | 客户端主动或意外终止连接 |
| TTFT | 首 token 延迟 | 从请求发出到收到第一个 token 的时间 |
| Network-observed time | 网络观测时间 | 从客户端视角测量的端到端延迟 |
| First generated token | 首个生成 token | 模型输出的第一个 token |
| Prefill | 预填充 | 处理输入提示词并构建 KV 缓存的阶段 |
