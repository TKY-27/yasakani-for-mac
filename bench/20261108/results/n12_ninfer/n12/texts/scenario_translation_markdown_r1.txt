## 备注

操作员需检查前缀复用（prefix reuse）已禁用，缓存命中计数为零，且没有无关的 GPU 进程处于活动状态。自然停止的响应仍视为有效观测；因客户端断开连接而丢失的响应则不视为有效。报告区分了服务器内部的 TTFT 与网络观测时间，并解释首个生成的 token 被分配给 prefill 阶段。

### 双语术语表 (Bilingual Glossary)

1. **Release procedure** / 发布流程：指软件版本从准备到最终发布的标准化操作步骤。
2. **Identifier** / 标识符：用于唯一识别系统内对象或参数的特定字符串或变量名。
3. **Request ID** / 请求 ID：用于追踪特定 API 调用或用户请求的唯一标识符。
4. **Max context** / 最大上下文长度：模型在处理输入时允许的最大 token 数量限制。
5. **KV dtype** / KV 数据类型：键值对（Key-Value）缓存中存储数据所使用的数值类型（如 float16, int8）。
6. **MTP rounds** / MTP 轮数：多 Token 预测（Multi-Token Prediction）过程中执行的迭代次数。
7. **Phase** / 阶段：发布流程中的特定步骤或时期。
8. **Fixture hash** / 测试夹具哈希值：用于验证测试数据完整性的哈希校验值。
9. **Prompt-token count** / 提示词 Token 计数：输入提示词中包含的 Token 总数。
10. **Warmup** / 预热：在正式测量前运行以稳定系统性能的非计时请求过程。
11. **Unmeasured request** / 未测量请求：不计入性能统计数据的请求。
12. **Sequential responses** / 顺序响应：按时间顺序依次返回的多个响应结果。
13. **Invalidate** / 使无效：标记数据或结果为不可用或错误。
14. **Headline** / 标题/主要结论：报告中展示的核心性能指标或摘要。
15. **Prefix reuse** / 前缀复用：利用相同前缀的缓存来加速后续请求的技术。
16. **Cache-hit count** / 缓存命中计数：成功从缓存中读取数据的次数。
17. **GPU process** / GPU 进程：占用图形处理单元资源的操作系统进程。
18. **TTFT** / 首字延迟 (Time To First Token)：从发送请求到收到第一个生成 Token 的时间间隔。
19. **Prefill** / 预填充：模型处理输入提示词并构建初始上下文的阶段。
20. **Observation** / 观测：在实验或测试过程中记录到的具体数据点或现象。
