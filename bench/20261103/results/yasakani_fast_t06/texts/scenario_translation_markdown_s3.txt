# 发布流程

发布负责人必须原样保留诸如 `request_id`、`max_context`、`kv_dtype` 和 `mtp_rounds` 等标识符。将正文翻译为中文，但不要翻译代码、JSON 键、命令行标志、文件名或表格中的值。

| Phase | Required evidence | Failure action |
|---|---|---|
| prepare | fixture hash and prompt-token count | stop before generation |
| warmup | one successful unmeasured request | restart the service |
| measure | five sequential responses | invalidate the complete block |
| publish | summary plus per-request rows | withhold the headline |

```json
{"model":"qwen3.6-35b-a3b","max_completion_tokens":1024,"seed":42,"stream":false}
```

## 备注

操作员需检查前缀复用功能已禁用、缓存命中计数为零，且没有无关的 GPU 进程正在运行。自然停止的响应仍被视为有效观察；因客户端断开连接而丢失的响应则不是。报告区分服务器内部的 TTFT 与网络观测时间，并解释首个生成的 token 归属于 prefill 阶段。

## 双语术语表

| English Term | 中文术语 | Note |
|---|---|---|
| Release procedure | 发布流程 | 指软件版本从开发到正式发布的标准化步骤。 |
| Release owner | 发布负责人 | 对发布过程及质量负主要责任的工程师或团队。 |
| Identifier | 标识符 | 用于唯一识别系统内实体（如请求）的字符串或变量。 |
| `request_id` | `request_id` | 请求的唯一标识符，用于追踪和日志关联。 |
| `max_context` | `max_context` | 模型处理的最大上下文长度限制。 |
| `kv_dtype` | `kv_dtype` | 键值缓存（KV Cache）的数据类型，影响内存使用和精度。 |
| `mtp_rounds` | `mtp_rounds` | 多 token 预测（Multi-Token Prediction）的轮数。 |
| Phase | 阶段 | 发布流程中的特定步骤或时期。 |
| Required evidence | 必需证据 | 证明该阶段成功完成所需的数据或日志。 |
| Failure action | 失败操作 | 当阶段失败时预定的应对措施。 |
| prepare | 准备 | 发布前的初始化和配置阶段。 |
| fixture hash | 测试夹具哈希 | 用于验证测试数据完整性的哈希值。 |
| prompt-token count | 提示词 token 数量 | 输入提示词转换为 token 后的计数。 |
| stop before generation | 生成前停止 | 在生成内容之前终止流程的操作。 |
| warmup | 预热 | 系统启动后进行的非测量性请求，以稳定性能。 |
| unmeasured request | 未测量请求 | 不计入性能指标统计的请求。 |
| restart the service | 重启服务 | 在失败后重新启动服务器进程。 |
| measure | 测量 | 收集性能指标的关键阶段。 |
| sequential responses | 顺序响应 | 按顺序发出的多个响应请求。 |
| invalidate the complete block | 使整个块失效 | 当测量失败时，丢弃所有相关数据。 |
| publish | 发布 | 正式公开结果或版本的阶段。 |
| summary | 摘要 | 对整体结果的概括性描述。 |
| per-request rows | 每请求行 | 针对每个单独请求的详细数据记录。 |
| withhold the headline | 保留标题 | 在失败时不公开主要结论或指标。 |
| `model` | `model` | JSON 中指定使用的模型名称。 |
| `max_completion_tokens` | `max_completion_tokens` | 生成内容的最大 token 数限制。 |
| `seed` | `seed` | 随机数种子，用于确保结果可复现。 |
| `stream` | `stream` | 是否启用流式输出的布尔值。 |
| prefix reuse | 前缀复用 | 复用已计算的前缀以加速后续请求的功能。 |
| cache-hit count | 缓存命中计数 | 缓存成功命中的次数统计。 |
| GPU process | GPU 进程 | 在 GPU 上运行的计算进程。 |
| TTFT | TTFT | 首 token 时间（Time to First Token）。 |
