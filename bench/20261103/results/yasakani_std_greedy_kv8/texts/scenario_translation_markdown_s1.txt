# 发布流程

发布负责人必须严格保留诸如 `request_id`、`max_context`、`kv_dtype` 和 `mtp_rounds` 等标识符。请将正文翻译为中文，但不要翻译代码、JSON 键、命令行标志、文件名或表格中的值。

| Phase | Required evidence | Failure action |
|---|---|---|
| prepare | fixture hash and prompt-token count | stop before generation |
| warmup | one successful unmeasured request | restart the service |
| measure | five sequential responses | invalidate the complete block |
| publish | summary plus per-request rows | withhold the headline |

## 备注

操作员需检查前缀复用（prefix reuse）已禁用，缓存命中计数（cache-hit count）为零，且没有无关的 GPU 进程处于活动状态。自然停止的响应仍被视为有效观察；因客户端断开连接而丢失的响应则不是。报告区分了服务器内部 TTFT 与网络观测时间，并解释首个生成的 token 被分配给 prefill 阶段。

## 双语术语表 (Bilingual Glossary)

1. **Release procedure / 发布流程**: The standardized steps and checks required to deploy a new model version or update.
2. **Release owner / 发布负责人**: The individual accountable for ensuring the release process is followed correctly.
3. **Identifier / 标识符**: A unique string or variable name used to reference specific data or configurations.
4. **Prose / 正文**: The narrative text of a document, as opposed to code or data structures.
5. **Command-line flag / 命令行标志**: A parameter passed to a command-line tool to modify its behavior.
6. **Filename / 文件名**: The name assigned to a file within a file system.
7. **Phase / 阶段**: A distinct stage in the release or testing process.
8. **Required evidence / 必需证据**: The specific data or logs needed to verify a phase's success.
9. **Failure action / 失败操作**: The predefined response to take when a phase does not meet its criteria.
10. **Fixture hash / 测试夹具哈希**: A cryptographic hash of the test data used to ensure consistency.
11. **Prompt-token count / 提示词元计数**: The number of tokens in the input prompt sent to the model.
12. **Generation / 生成**: The process of the model producing output tokens.
13. **Warmup / 预热**: An initial phase to stabilize the system before formal measurement.
14. **Unmeasured request / 未测量请求**: A request sent to the system that is not included in performance metrics.
15. **Restart the service / 重启服务**: The action of stopping and starting the application service again.
16. **Sequential responses / 顺序响应**: A series of responses generated one after another in a specific order.
17. **Invalidate / 使无效**: To render data or results unusable or unreliable.
18. **Complete block / 完整块**: A full set of data or test results that must be discarded if one part fails.
19. **Summary / 摘要**: A concise overview of the results.
20. **Per-request rows / 每请求行**: Data entries corresponding to individual requests.
21. **Withhold / 扣留**: To hold back or delay the release of information.
22. **Headline / 标题**: The main title or primary result of the report.
23. **Prefix reuse / 前缀复用**: A caching mechanism where common prompt prefixes are reused to save computation.
24. **Cache-hit count / 缓存命中计数**: The number of times a request is served from the cache rather than recomputed.
25. **GPU process / GPU 进程**: A software process utilizing the graphics processing unit for computation.
26. **Observation / 观察**: A recorded data point or result from a test run.
27. **TTFT (Time To First Token) / 首字延迟**: The time taken from sending a request to receiving the first generated token.
28. **Prefill / 预填充**: The initial phase of inference where the model processes the entire input prompt.<|im_end|>
